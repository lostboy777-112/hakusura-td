# ハクスラTD｜Loot Lane Defense

ハクスラ × MOBA（LoL）× タワーディフェンスに、「モンスターサバイバル」系のサバイバル要素を組み合わせた、ブラウザで遊べる2Dゲームです。GitHub Pagesに置けばそのまま公開できます。

## 遊び方

- **目的**: 広いマップの中心にある 💎 コアを、四方から押し寄せるモンスターの大群から守る。45秒ごとにWAVEが進み敵が強化される。コアHPが0で敗北。
- **ヒーロー選択**: 5人から選べる。
  - ⚔️ 剣士レオン（斬撃・バランス）／🔮 魔女ルナ（追尾魔弾・高火力）／🏹 射手シルフ（貫通矢・高速）／🥷 忍者ハヤテ（双短剣・最速）／🪓 戦士ゴウ（大斧・高HP）
- **操作**: 画面左側をドラッグでバーチャルスティック移動（慣性つきでヌルヌル動く）。PCは WASD・矢印キー・クリック移動。攻撃は自動。
- **スキル**（ボタン／Q・E・Rキー）: ヒーローごとに固有。Q=主力スキル、E=移動・回避、R=必殺技（例：剣士R「聖撃波」、魔女R「メテオシャワー」、戦士R「大旋風」）。
- **レベルアップ**: 敵が落とす経験値ジェムを集めるとレベルアップ。3つの強化候補から1つ選択（攻撃・攻速・投射物+1・吸血・タワー強化・コア修復など12種）。
- **タワーディフェンス**: コア周りの台座（＋）をタップしてタワーを建築（アロー／キャノン／フロスト／スナイパー）。タップで強化（Lv3まで）・売却も可能。
- **ハクスラ要素**: 敵を倒すと装備がドロップ（武器／防具／お守り、レア度はノーマル〜レジェンダリー。エリート・ボスは高確率）。歩いて拾い、🎒 装備画面で付け替えます。
- **ボス**: 4WAVEごとにボス出現（装備を必ず2つドロップ）。
- **ヒーローが倒れた場合**: 5秒でコア付近に復活。敗北条件はコア破壊のみ。
- **演出**: カメラ追従、パーティクル、ダメージ数字、ノックバック、画面シェイク、ミニマップ搭載。

## データとランキング

- 未設定でも遊べます。ランキングとベスト記録は端末内（localStorage）に保存されます。
- Supabaseを設定すると、ランキングがオンライン共有され、ベスト記録がクラウドに保存されます。手順は [SUPABASE.md](SUPABASE.md) です。
- 設定（プロジェクトURLとanonキー）は端末内だけに保存され、このリポジトリには含まれません。

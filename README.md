# ハクスラTD｜Loot Lane Defense

ハクスラ × MOBA（LoL）× タワーディフェンスを組み合わせた、ブラウザで遊べる2Dゲームです。GitHub Pagesに置けばそのまま公開できます。

## 遊び方

- **目的**: レーンを進む敵の群れから 💎 コアを守る。敵がコアに届くとコアHPが減り、0で敗北。Waveを重ねてスコアを伸ばします。
- **ヒーロー操作**: 画面ドラッグ／クリックで移動先を指定、または WASD・矢印キーで移動。攻撃は射程内の敵へ自動です。
- **アビリティ**（ボタン／キー）:
  - Q 🌀 旋風斬: 周囲の敵に大ダメージ（CD 8秒）
  - E ❄️ 氷結ノヴァ: 周囲の敵を3秒スロー＋小ダメージ（CD 12秒）
  - R ☄️ メテオ: 敵の頭上に隕石8発（CD 35秒）
- **タワーディフェンス**: 空き地の ⬜ パッドをタップしてタワーを建築（アロー／キャノン／フロスト／スナイパー）。建てたタワーはタップで強化（Lv3まで）・売却ができます。
- **ハクスラ要素**: 敵を倒すと装備がドロップ（武器／防具／お守り、レア度はノーマル〜レジェンダリー）。歩いて拾い、🎒 装備画面で付け替えます。レベルアップ時は3つの強化候補から1つを選択。
- **ボス**: 5Waveごとに 🧌 ボス出現（コアダメージ5、装備を必ず2つドロップ）。
- **ヒーローが倒れた場合**: 5秒でコア付近に復活します。敗北条件はコア破壊のみです。

## データとランキング

- 未設定でも遊べます。ランキングとベスト記録は端末内（localStorage）に保存されます。
- Supabaseを設定すると、ランキングがオンライン共有され、ベスト記録がクラウドに保存されます。手順は [SUPABASE.md](SUPABASE.md) です。
- 設定（プロジェクトURLとanonキー）は端末内だけに保存され、このリポジトリには含まれません。
